# DevOps portfolio

Files: index.html (project list + filter), project.html (detail page, reads ?id=), projects.js (all project data), style.css, images/.

## Add a project
Copy an entry in projects.js, change `id`, `tool`, text, commands, repo link. Add screenshots to images/.

## Publish on GitHub Pages
1. Create a repo and push these files to the main branch.
2. Repo Settings > Pages > Deploy from a branch > main / root.
3. Site goes live at https://YOUR-USERNAME.github.io/REPO-NAME/
